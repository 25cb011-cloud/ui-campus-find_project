# CampusFind – Campus Lost-and-Found System

**A College Campus Lost-and-Found Website UI**

## 1. Project Overview

CampusFind is a web-based Campus Lost-and-Found System UI designed to help students and staff report lost belongings and discover items found around their college campus.

Students frequently lose personal belongings such as ID cards, books, water bottles, keys, wallets, calculators, and bags. Finding these items can be difficult without a centralized reporting platform.

CampusFind proposes a simple digital solution where users can browse lost-and-found listings, report missing or found items, view item details, and explore the process of claiming recovered belongings.

This project focuses on designing an attractive, user-friendly website interface that demonstrates how a campus lost-and-found platform could work.

## 2. Problem Statement

In colleges, lost belongings are often reported through informal communication, classroom announcements, notice boards, or student messaging groups. These methods can make it difficult to locate an item or connect it with its owner.

A centralized lost-and-found platform can make item information easier to access and help organize reports in one place.

## 4. Main UI Screens

The website design includes the following 10 screens:

1. **Landing Page** – Introduces CampusFind and provides navigation to the main features.
2. **Login Page** – Displays the sign-in interface.
3. **Registration Page** – Provides a form for creating a user account.
4. **Dashboard** – Presents sample statistics, recent listings, and quick actions.
5. **Browse Items** – Displays lost-and-found items with search and filter controls.
6. **Report Lost Item** – Provides a form to report missing belongings.
7. **Report Found Item** – Provides a form to list an item found on campus.
8. **Item Details** – Displays information about a selected item.
9. **My Reports** – Presents an interface for viewing and managing submitted reports.
10. **Claim and Recovery Center** – Shows the proposed item-claim and recovery workflow.

- A laptop or desktop computer.
